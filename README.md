⋆ Funcionalidades

O sistema oferece um menu interativo com as seguintes operações:

📖Cadastrar livros: adicionar livros ao sistema.

📖Listar livros: visualizar os registros cadastrados.

📖Consultar livros: localizar livros por meio de um código.

𓂃✍︎ Validar entradas: tratar opções inválidas e registros inexistentes.


⋆ Tecnologias utilizadas

. ۫ ·Python 3 — Desenvolvimento da aplicação.

. ۫ ·Git e GitHub — Versionamento e colaboração.

. ۫ ·Visual Studio Code — Ambiente de desenvolvimento.

⋆ Como executar

1. Clone o repositório:

git clone https://github.com/USUARIO/sistema-biblioteca.git

2. Acesse a pasta do projeto:

cd sistema-biblioteca

3. Execute o programa:

python main.py


⋆ Funcionamento

O programa funciona por meio de um menu no terminal, no qual o usuário seleciona a operação desejada.

===== SISTEMA DE BIBLIOTECA =====

1 - Cadastrar livro
2 - Listar livros
3 - Consultar livro
0 - Sair

Escolha uma opção:

Os registros são armazenados temporariamente durante a execução do programa, utilizando listas e dicionários.
